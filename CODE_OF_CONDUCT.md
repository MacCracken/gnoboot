# Code of Conduct

gnoboot follows the AGNOS family code of conduct.

## Standards

- Respectful, constructive, technically focused communication
- Disagreements about design or implementation are normal and
  expected; making them personal is not
- Critique the code, not the person
- Cite sources, run the gates, show your work
- Acknowledge mistakes and learn from them

## Scope

This code of conduct applies to all gnoboot project spaces —
issue trackers, pull requests, commit messages, code review
comments, and any other community space tied to the project.

## Reporting

Concerns can be raised via the standard AGNOS family channels.
See [SECURITY.md](SECURITY.md) for security-specific reporting.

For inter-personal conduct issues, contact the AGNOS project
lead.

## Enforcement

The AGNOS project lead is the enforcer of last resort. Disputes
about technical decisions are resolved by reading the relevant
ADR, architecture note, or roadmap entry — and if those don't
cover the disagreement, by filing one for the next decision.
